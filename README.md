# yonsei.league (텍스트 야구 대전 게임)

프로그래밍실습 기말 프로젝트

투수는 던질 칸과 구종을 고르고 타자는 공이 올 칸을 예측해서 치는 C언어 콘솔 야구 게임입니다.
마구마구 같은 야구 게임의 투수와 타자의 수 싸움을 수업에서 배운 C 문법만으로 만들었습니다.


# 팀원
신인섭, 2026245144 --> display.c (입력·화면 출력), main.c (경기 흐름)
황지현, 202624028 --> play.c (투구·타격·판정·주자 진루) 


# 게임 규칙

- 스트라이크존은 1~9번 칸(3×3), 0번은 존 밖으로 빠지는 볼
- 투수: 던질 칸(0~9)과 구종(1 직구, 2 변화구) 선택
- 타자: 노릴 칸(1~9)을 고르거나 0(지켜보기)
- 지켜보면 존 안은 스트라이크, 존 밖은 볼
- 스윙하면 노린 칸에 가까울수록 잘 맞음 (변화구는 더 어려움)
- 맞히면 파울 또는 타구(아웃 / 단타 / 2루타 / 3루타 / 홈런)
- 3스트라이크 삼진, 4볼 볼넷, 3아웃 공수 교대
- 초에는 내가 타자, 말에는 내가 투수가 되어 컴퓨터 팀과 1~9이닝 경기


# 파일 구성

(파일-->내용)

`game.h` --> 상수(#define), 구조체(Pitch, Situation, Team), 함수 원형 
`display.c` --> read_number, print_zone, print_mark, print_bases, print_scoreboard 
`play.c` --> is_next_to, choose_pitch, choose_swing, judge, hit_result, run_bases, walk, play_at_bat 
`main.c`--> main, play_half 

사용한 C 개념은 조건문·반복문, 배열, 함수, 구조체, 포인터(`->`), 난수(`rand`, `srand`), 입력 검증(`scanf` 반환값) 입니다.


# 실행 방법

Visual Studio로 집행합니다
1. 빈 프로젝트(C++) 만들기
2. 소스 파일에 `display.c`, `play.c`, `main.c`, 헤더 파일에 `game.h` 추가
3. `Ctrl + F5`로 실행

저장소에서 Code → Download ZIP으로 받은 파일로 위 순서대로 실행할 수 있습니다.
